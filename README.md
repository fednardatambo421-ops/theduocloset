# The Duo Closet — GitHub upload folder

Upload **everything in this folder** to the top level of a new GitHub repository.

Required files:

- `index.html`
- `styles.css`
- `script.js`
- `assets/hero-sneaker.png`

Then enable GitHub Pages: repository **Settings** → **Pages** → **Deploy from a branch** → `main` → `/ (root)` → **Save**.
